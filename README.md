# Nfnitloop Tap

## How do I install these formulae?

`brew install nfnitloop/tap/<formula>`

Or `brew tap nfnitloop/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nfnitloop/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
